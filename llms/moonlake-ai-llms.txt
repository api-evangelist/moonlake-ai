# MoonLake AI

> Moonlake AI Inc. builds world models and simulation infrastructure for embodied AI. Its hosted API turns an image, video, or text description into physically accurate, simulation-ready 3D models — assets shipped with baked-in physics and articulation (joints, ranges, drive limits) that export directly to USD, NVIDIA Isaac Sim, and MuJoCo. Teams generate simulation environments and digital twins in hours. Backed by Threshold (formerly DFJ), AIX Ventures, and NVIDIA's venture arm; named to the CB Insights AI 100 (2026). Headquartered in San Francisco, CA.

## API

- [Generation API](https://moonlakeai.com/): Submit a generation job to POST https://app.moonlakeai.com/api/jobs/ with an `Authorization: Bearer {api_key}` header. Input is a prompt plus optional reference images or video; output is a physically accurate, sim-ready 3D asset. Access is enterprise (Book Demo); there is no public self-serve sign-up.

## Authentication

- [Authentication profile](authentication/moonlake-ai-authentication.yml): HTTP Bearer API key in the Authorization header. Unauthenticated requests return HTTP 401 `{"error":"Missing API key"}`.
